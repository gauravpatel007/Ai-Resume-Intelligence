# AI Resume Intelligence - Detailed Feature Overview

This document provides an in-depth, tab-by-tab breakdown of the features and capabilities available in the AI Resume Intelligence platform, separated into the **User (Candidate) Side** and the **Admin (Recruiter) Side**.

---

## 👤 User (Candidate) Dashboard

The Candidate portal empowers job seekers to leverage AI to parse their resumes, identify weaknesses, and prepare for interviews.

### 1. Dashboard Tab (Home)
- **Personalized Overview:** A welcome screen displaying the candidate's email and high-level platform status.
- **Quick Action Links:** Dynamic, glassmorphism-styled cards that act as shortcuts to the three core workflows: Uploading a Resume, Analyzing Skill Gaps, and Starting an AI Interview.
- **Responsive Layout:** A collapsible sidebar and mobile-friendly grid system ensure the dashboard is accessible across all devices.

### 2. Upload Resume Tab
- **Drag-and-Drop Interface:** Users can drag their PDF resumes into a dropzone or browse local files.
- **Real-Time Processing Status:** Displays step-by-step progress bars (e.g., "Uploading...", "Extracting Text...", "AI Parsing...").
- **AI-Powered Parsing:** The backend utilizes PDF extraction libraries (PyPDF2) to pull raw text, which is then passed to a Large Language Model (Google Gemini).
- **Structured Data Extraction:** The LLM uses strict JSON schemas to accurately categorize:
  - **Skills:** Separates technical abilities from soft skills.
  - **Experience:** Extracts job titles, companies, durations, and bullet-point responsibilities.
  - **Education:** Identifies degrees, institutions, and graduation years.
  - **Contact Info:** Parses emails, phone numbers, and social links (LinkedIn, GitHub).
- **Database Synchronization:** Automatically updates the candidate's PostgreSQL/SQLite database record with the newly parsed structured data.

### 3. My Profile Tab (Extracted Profile)
- **Visual Resume UI:** Transforms the extracted JSON data into a clean, human-readable profile page.
- **Skills Badges:** Displays technical and soft skills as color-coded chips for easy scanning.
- **Chronological Timelines:** Renders work experience and education history in visually distinct timeline blocks.
- **Raw JSON Viewer:** An optional toggle for technical users to inspect the exact raw JSON output generated by the AI, ensuring transparency in how their data was parsed.

### 4. Skill Gaps Tab
- **Target Role Input:** Candidates type the exact title of the job they are aiming for (e.g., "Senior Frontend Engineer").
- **Comparative AI Analysis:** The system compares the candidate's extracted profile against industry-standard requirements for the targeted role using AI.
- **Missing Skills Identification:** Clearly highlights critical skills the candidate currently lacks.
- **Actionable Learning Paths:** Generates personalized study recommendations, specific topics to learn, and practical project ideas to help the candidate bridge their skill gap.

### 5. Interview Tab
- **Context-Aware Question Generation:** Based on the candidate’s uploaded resume and a specified target role, the AI generates a customized list of mock interview questions (behavioral and technical).
- **Interactive Q&A Session:** Candidates can type their answers directly into a text area within the platform.
- **Instant AI Feedback:** The AI evaluates the submitted answers, scores them, and provides constructive, detailed feedback on how to improve the response based on the STAR method and industry expectations.

## 🛡️ Admin (Recruiter) Dashboard

The Admin portal is built for HR professionals and recruiters to efficiently search, filter, analyze, and compare candidates using both exact filters and advanced semantic AI.

### 1. Dashboard Tab (Analytics & Overview)
- **Real-Time Analytics:** Displays high-level metrics including total candidates registered, total searches performed, and recent system activity. Data polls automatically every 5 seconds.
- **Trending Roles Chart:** A dynamic visualization (powered by Recharts) showing the most frequently searched job roles over time.
- **Saved Collections (Templates):** Admins can create and save frequent search queries (e.g., "Mid-Level Data Scientist"). Clicking a collection instantly pre-fills the search parameters and executes a query, saving time on repetitive tasks.

### 2. Candidate Search Tab (Exact Match)
- **Granular Database Filtering:** Recruiters can query the candidate database using strict, structured filters:
  - Target Job Role.
  - Required Skills & Preferred Skills.
  - Minimum Years of Experience.
  - Required Degree Level (e.g., Bachelor's, Master's, PhD).
- **Direct Name Lookup:** A dedicated search bar to instantly pull up a specific candidate's profile by name.
- **Expandable Results:** Search results are displayed in a clean list where recruiters can expand individual rows to view a summary of the candidate's matching qualifications.

### 3. Semantic Search Tab (AI Context Matching)
- **Unstructured Job Description Parsing:** Recruiters can paste an entire, unstructured job description directly into a text box.
- **One-Click Presets:** Built-in templates (e.g., "Python Backend", "DevOps & Cloud") allow recruiters to instantly load complex job descriptions for quick candidate matching.
- **Neural Embedding Matching:** The backend uses `SentenceTransformers` (`all-MiniLM-L6-v2`) to convert the job description and candidate profiles into vector embeddings. It calculates cosine similarity to find candidates who match the *intent* and *context* of the job, even if exact keywords are missing.
- **Evidence Snippets:** The UI extracts and highlights the exact sentence/passage from the candidate's resume that drove the high semantic match score, providing complete transparency.
- **Must-Have Skill Audits:** Separates the AI semantic score from hard requirements, displaying color-coded checks (✓/✗) to instantly show if a candidate possesses absolute non-negotiable skills.

### 4. Candidate Database (Users List)
- **Global Roster:** A paginated, comprehensive list of all registered candidates in the system.
- **Profile Quick-View Modal:** Clicking on any candidate opens a detailed modal containing:
  - Contact information (Email, Phone, Links).
  - Complete work and education history.
  - The raw extracted resume text for manual review.

### 5. Compare Mode Tab
- **Floating Compare Tray:** While browsing search results (either Exact or Semantic), recruiters can click "+ Compare" to add candidates to a persistent floating tray.
- **Side-by-Side Matrix:** Renders a dynamic, multi-column comparison table aligning selected candidates side-by-side.
- **Dimensional Comparison:** Compares candidates simultaneously across key dimensions: Total Experience, Education Level, Matched Skills, Missing Skills, and overall AI Semantic Score.

### 6. Export & Audits Tab
- **PDF Report Generation:** Admins can export individual candidate profiles, search results, or semantic match breakdowns into beautifully formatted PDF reports, ready to be shared with hiring managers.
- **System Audit Log:** Maintains a secure history of all exported reports and system activities, allowing admins to track usage, compliance, and past hiring workflows.
